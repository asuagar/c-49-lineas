# C en 49 líneas

Un tutorial progresivo de programación en C mediante ejemplos breves y autocontenidos. Cada archivo presenta un concepto, lo explica en sus comentarios y contiene un programa que se puede compilar y ejecutar por separado.

Los ejemplos tienen un máximo de **49 líneas**, incluida su explicación. Puedes seguirlos en orden o abrir un archivo concreto para repasar un concepto.
